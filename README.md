# Essencial Ateliê

Crie um sistema web chamado Essencial Gestão Ateliê. O design deve ser minimalista, com fontes legíveis, botões grandes e de alto contraste, focado em acessibilidade para usuárias com baixa literacia digital. Crie um menu de navegação lateral simples, sem submenus complexos, contendo apenas as opções: Início, Insumos, Produtos e Ficha Técnica.
